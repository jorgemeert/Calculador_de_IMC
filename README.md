Uma ferramenta simples e funcional para cálculo de Índice de Massa Corporal (IMC), desenvolvida para estudar a manipulação do DOM e lógica de funções em JavaScript.

## ⚙️ Funcionalidades

* **Cálculo em Tempo Real:** O usuário insere peso e altura e obtém o resultado ao clicar no botão.
* **Tabela de Referência:** Exibição clara das categorias de IMC para fácil interpretação dos resultados.
* **Interface Dinâmica:** Uso de CSS moderno com gradientes e sombras para uma melhor experiência de usuário.

## 🧠 Conceitos Técnicos Aplicados

Neste projeto, foquei em consolidar os seguintes aprendizados:

* **Manipulação de DOM:** Uso de `document.getElementById` para capturar valores de inputs e exibir resultados dinamicamente no HTML.
* **Lógica de Programação:** Implementação de funções matemáticas para o cálculo: $$IMC = \frac{peso}{altura^2}$$
* **Estilização Avançada:** * Uso de `linear-gradient` no background.
    * Efeitos de `hover` em botões.
    * Organização de layout com seletores descendentes em CSS.
